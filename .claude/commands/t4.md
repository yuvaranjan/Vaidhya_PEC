## 3. Rules you do not break

- **The seed must stay idempotent.** Every insert gets an `on conflict` clause. Someone
  will run it twice at 3am.
- **Every demo doctor serves every jurisdiction.** An unrealistic catchment area is a far
  smaller problem than an empty queue on stage.
- `question_bank` is a **translation cache, not a question source.** The LLM authors
  questions freely. A cache miss is normal. The system is correct with it empty.
- `stock_items.status` is a generated column. Never write it by hand.
- **Twilio is the highest external risk in the project.** Indian DLT registration and
  Twilio trial limits can block SMS to Indian numbers for reasons that have nothing to do
  with our code. Prove it end to end early; if it cannot be proven, fall back to the
  WhatsApp sandbox or Voice/IVR and cut it from the critical demo path. Say so loudly in
  your status file either way.
